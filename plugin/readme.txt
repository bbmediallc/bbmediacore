A WordPress plugin providing core functionality for B&B Media websites, including a custom dashboard, support form, and branding enhancements.

== Description ==

BB Media Core is a WordPress plugin designed to enhance the admin experience for B&B Media's clients. The plugin provides:

* A branded admin footer.
* A custom login screen with branding.
* A custom dashboard replacing the default WordPress dashboard.
* A support form for submitting tickets directly to B&B Media.
* A shortcode to display the latest blog posts from B&B Media's feed.

This plugin is ideal for agencies looking to white-label WordPress admin interfaces and streamline client support.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/bb-media-core` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to the WordPress admin area to see the custom dashboard.

== Frequently Asked Questions ==

= What does this plugin do? =
BB Media Core customizes the WordPress admin area by adding branding, a custom dashboard, and a support form for easier client interaction.

= Can I use this plugin for my own agency? =
Yes, but you may need to adjust branding elements like logos and links to suit your agency.

= Does this plugin work on all WordPress versions? =
This plugin has been tested on WordPress 6.9 and higher. Ensure your WordPress and PHP versions meet the requirements.
